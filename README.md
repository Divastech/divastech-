# Divastech Website

A responsive six-page static website for Divastech, based in Port Harcourt, Rivers State, Nigeria.

## Pages
- `index.html` — Home
- `about.html` — About Divastech
- `technology.html` — Website-building mentorship
- `trading-crypto.html` — Beginner and intermediate trading and crypto education
- `beauty-hair.html` — Hair installation services and training
- `contact.html` — Contact and WhatsApp

## Technology
Built with plain HTML, CSS and vanilla JavaScript. No framework, package installation or build step is required.

## Run locally
Open `index.html` in a browser, or serve this folder with any static web server.

## Cloudflare Pages
1. In Cloudflare, open Workers & Pages and create a Pages project.
2. Connect the GitHub repository `Divastech/divastech-`.
3. Select production branch `main`.
4. Choose framework preset **None**.
5. Leave the build command blank.
6. Set the build output directory to `/` (or `.`, if the dashboard requires a relative path).
7. Deploy. Cloudflare will provide a `.pages.dev` address.
